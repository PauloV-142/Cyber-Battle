O que é um sistema de controle de versão e qual a sua principal funcionalidade no dia a dia do desenvolvedor???
R: Um VCS serve para organizar o estado do sistema confome as modificações vão sendo feitas. Suas principais funcionalidades são:
- Permitir roolback para qualquer versão antiga
- Permitir que todos os desenvolvedores possam ter o mesmo código sem muitas complicações
- Trazer mais organização para o processo de desenvolvimento singular ou em equipe.
- Trazer uma melhor visibilidade sobre todas as alteração feitas.

Explique, com suas palavras, a diferença entre um sistema de Controle de Versão Centralizado(como o SVN) e um distribuido(como o Git).
R:  O SVN utiliza um servidor central que gerencia todas as operações com o código lá. Por causa disso é necessária uma conexão de internet consistente e confiável, senão os processos ocorrerão com muita lentidão.
GIT também possui (geralmente) um servidor, mas com o propósito de salvar os arquivos (pasta .git) e permitir que os desenvolvedores façam o 'clone' (donwload) e o 'push' (upload). O resto das operações com o código e repositório: Commits, Branches e Merge são feitas localmente.
